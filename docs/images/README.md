# README illustration

`mcp-demo.gif` illustrates local MCP, Desktop Live Sync and Web Live Sync.
It is a conceptual diagram, not a recording of Apache Hop. It contains no
project data or real server addresses. `mcp-demo.png` is its static alternative.
The README uses the static image when the viewer prefers reduced motion.

Regenerate with Python 3 and Pillow:

```sh
python scripts/docs/render-readme-demo.py
```

The renderer uses the installed Segoe UI or DejaVu Sans font; fonts are not
distributed. The animation loops over three scenes in 11.7 seconds without
flashing. Source and generated illustrations use the repository's Apache 2.0
license.
